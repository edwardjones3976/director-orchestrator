A-16 — Firecrawl — bounded public research

Same contract as A-15: public sources only, no repository context, no credentials, no external effect, no verdict.

One bounded public query: operational guidance for the LangGraph Postgres checkpointer — schema and namespace isolation between deployments, behaviour across restart, and backup and restore practice. The results feed WO-08's lifecycle and the recovery section of the user guide.

Two surfaces, kept distinct. The repository Firecrawl lane executes on the LangGraph primary path and needs FIRECRAWL_API_KEY present in the deployment; it has no legacy adapter and no entry in .env.example, so enabling it is the owner action in §6. Separately, a Firecrawl MCP server is connected to the Director's own session and has already run one query under this contract; its result is recorded as Director-side research evidence and is not evidence that the repository lane is enrolled or live.

Result already returned by the Director-side surface, 2026-09-09. The n8n Webhook node supports Header, Basic and JWT authentication credentials on the inbound hop; response code and body are controllable, and the Respond to Webhook node is the mechanism when the response must be shaped by the workflow; and for an Authorization: Bearer <token> outbound call the correct generic auth type is httpBearerAuth, not httpHeaderAuth, which is for custom headers such as X-API-Key. The Webhook node also offers an IP allowlist and a bot-ignore option. This changes A-06, which previously said only "bearer secret through an n8n credential": it now specifies httpBearerAuth for the outbound call to /v1/intake, header or JWT auth on the inbound Slack hop, and Respond to Webhook for the non-2xx error mapping.

A-17 — GitHub Copilot Lite — hygiene observation

One requested hygiene observation on the frozen exact candidate, after every required check is green. Non-gating: it creates no production credit, holds no gate or authority, and never triggers on every push. Findings are validated independently before any of them blocks anything.

At most three conditional attempts. Stop on success; a further attempt requires a genuine temporary failure, and a third requires materially new information or a substantially different transport. Without an authenticated contact the lane fails closed as unavailable, which records no verdict and counts as waste. A substantive Copilot-authored fix would make Copilot a material author and ineligible to review that candidate — so findings only, never patches.

7. What this matrix does not claim

Lane membership and an allocation share do not attest that a provider route is enrolled, authenticated or live. No packet here has been dispatched: the Director holds no provider transport in this session, and dispatching one would be an external action requiring the owner. Every assignment above is a prepared work order awaiting owner launch. The profile sheets grant no authority, and a documented route is not an authorized one.
