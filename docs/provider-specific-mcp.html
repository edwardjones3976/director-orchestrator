Provider-specific MCP adapters

Two local stdio servers expose four explicit tools. The director-xai server offers xai_status and xai_ask; the director-zai server offers zai_status and zai_ask. Each server names one provider, reads only its credential, and calls only its pinned provider endpoint. No generic provider argument or fallback router is accepted.

Perplexity has a separate official MCP server at https://api.perplexity.ai/mcp. Register it as its own MCP entry with PERPLEXITY_API_KEY supplied through the host environment. Its tools remain Perplexity research calls; they do not route to Grok or Z.ai.

These are advisory model calls. They create no Director work packet, production credit, review verdict, assignment, or external effect. Use the Director's existing admission, budget, review and merge paths for project work. MCP host registration alone grants no provider authority.

Readiness and spending

Status calls are free and report booleans only. Ask calls refuse by default. Both DIRECTOR_MCP_PAID_CALLS_ENABLED=true and the matching provider switch (XAI_MCP_ENABLED=true or ZAI_MCP_ENABLED=true) must be present in the server process. Grok reads XAI_API_KEY and Z.ai reads ZAI_API_KEY at call time. Z.ai additionally requires the owner's production activation record digest in ZAI_PRODUCTION_ACTIVATION. The old Z.ai trial ended on 29 September 2026 and is not an available route. Never put a credential value in an MCP registration command or tracked file.

Ask input is capped at 24 KB, both requests disable model tools, output is bounded to 4000 tokens, and receipts are written under ~/.codex/provider-mcp-receipts/<provider>/ outside worktrees. Calls are capped at 40 xAI or 20 Z.ai attempts per UTC day. A repeated input digest refuses instead of silently retrying an ambiguous previous attempt. These limits apply only to this advisory interface; Director's own budgets and ledger remain authoritative for project execution.

Local registration

From the repository root, run the module with Python 3.12. Set PYTHONPATH in each host entry to the absolute repository root, using the host's environment configuration. Register each server separately:

py -3.12 -m scripts.provider_mcp.xai
py -3.12 -m scripts.provider_mcp.zai

For Codex, the official Perplexity remote registration is:

codex mcp add perplexity --url https://api.perplexity.ai/mcp --bearer-token-env-var PERPLEXITY_API_KEY

Do not enable paid-call switches merely to test the MCP handshake. Verify initialize, tools/list, and the status tools first. Run py -3.12 -m unittest tests.test_provider_mcp -v to verify protocol separation and default refusals without network calls.
