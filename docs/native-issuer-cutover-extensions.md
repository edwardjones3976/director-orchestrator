# Native issuer and GitHub target extensions

This source implements additional capture routes; it neither enrolls an issuer nor activates LangGraph. The existing Claude security and Cursor independent-review installer defaults are unchanged. Explicit `-Provider openai` is eligible only for security; `-Provider gemini` is eligible for security or independent review. Nondefault providers use separate installation directories, preserving existing keys and state. Registry adoption remains a separate, owner-controlled operation after exact-release review and CI by already trusted eligible authorities. A new issuer cannot approve its initial adoption, and two Gemini issuers cannot supply independent provider families.

The native workers retain protected broker/worker identities, executable pins, complete runtime ACL verification, create-once claims and protected captures. Codex uses ChatGPT login status and bounded ephemeral JSON execution with the installed transport's disabled tool/config flags. AGY uses the installed 1.1.27 stream shape and documented stdin user event. Both reject mismatched challenge, packet digest, nonce, native session, duplicated terminal events, tools, unsupported event categories and non-ACCEPT verdicts before signing. Requested models are recorded separately; observed model and account remain unknown in these streams.

AGY requires separately provisioned `-NativeHome`, `-NativeProject` and `-NativeDenyHook`, all inside protected runtime roots. The deny-all permission settings and wildcard hook must match the protected policy. The installer does not create authentication, copy account files or pretend that valid JSON proves native enforcement. Initial enrollment must establish the actual native account mode from the authenticated native UI, prove this exact runtime enforces the hook, and verify native state writes do not allow policy/launcher replacement. Current CLI exposes no machine-readable account/project observation endpoint. An operator cannot close this gap by copying a requested project or supplying an invented observed account. If protected home/state separation fails, no issuer enrollment is valid. The installer ancestry/mask correction remains a separate Antigravity-authored package.

Native protocol sources: [AGY headless stream](https://antigravity.google/docs/cli/headless/), [AGY installation and authentication](https://antigravity.google/docs/cli-install?app=antigravity), [AGY project request binding](https://antigravity.google/docs/cli/projects/), and the existing pinned `native_codex_transport.py` integration. Preserved native-attempt-001 is evidence of the AGY 1.1.27 event shape, not qualified host containment. No new paid provider run was performed for this implementation.

The Linux engineering worker additionally requires a root-protected, nondelegated `cgroup_root` on a cgroup v2 mount with kernel `cgroup.kill` support. Each command joins a fresh child group before UID reduction and execution. Every exit kills that whole group and verifies `populated 0`; escaping the original session or process group cannot escape this boundary. A changed worker configuration digest requires new host qualification. The real Linux regression executes these production helpers against new disposable groups; it does not qualify the production guest, native authentication or network isolation.

GitHub mark-ready authority now requires `LANGGRAPH_PRIMARY_EXTERNAL_EFFECT_BASE_SHA` and `LANGGRAPH_PRIMARY_EXTERNAL_EFFECT_HEAD_SHA`, alongside the existing single repository allowlist and positive `LANGGRAPH_PRIMARY_EXTERNAL_EFFECT_PULL_NUMBER`. These are actual PR coordinates captured and approved by the owner, independent of the deployed candidate or task source revision. They enter the existing effect approval digest. Missing or malformed coordinates fail closed. The existing gateway rechecks both revisions immediately before mutation and in terminal readback; no merge authority is added. The underlying GitHub mark-ready API has no atomic expected-head parameter, so readback remains essential when a concurrent branch update races the preflight GET.
