HTML is the canonical documentation format

Owner direction, 3 October 2026 Pacific: aggressively migrate the substantial majority of Director-Orchestrator's human-facing Markdown documents to HTML immediately. HTML is the maintained source, not an alternative rendering of Markdown.

Applies to every administrator and provider

Use HTML for project guides, operating procedures, design explanations, staff and contact pages, checklists, plans, handoffs and reports. Codex is the overall Director and Foreman; Claude directs project completion; Cursor is the third administrator. These appointments and existing file ownership remain in force.

Working format

Write semantic, accessible HTML with a document title, language, UTF-8 encoding, viewport, ordered headings, descriptive links and table headers. Use the shared local stylesheet and templates. Documents must remain readable offline without remote scripts, fonts or tracking. Keep code examples escaped and preserve technical contracts exactly.

Narrow format exceptions

Machine-required AGENTS.md, CLAUDE.md, SKILL.md and platform templates retain their discovered names and point to canonical HTML guidance. Model prompt contracts and JSON/YAML schemas retain their contractual formats. GitHub and Slack messages use their supported transport formatting and link to HTML documents. Immutable historical evidence is preserved, not regenerated. Independently led excluded projects are outside this migration.

Validation and ownership

Update local links, document consumers, renderers, tests and CI together. Each generated provider sheet is rendered directly from its structured profile to HTML. New human-facing Markdown requires an explicit machine-contract or historical-evidence justification. Never maintain competing Markdown and HTML versions of an active guide.

The format change grants no new runtime, access, spending, review or release authority. Keep one writer and one eligible final reviewer, check exact current sources, and distinguish prepared, tested, reviewed, merged, deployed and live-verified work.
