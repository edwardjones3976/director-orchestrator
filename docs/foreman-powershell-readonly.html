Foreman PowerShell read runner

The scripts.foreman_mcp.powershell_readonly stdio MCP exposes four tools: status, read one file, list one directory, and search one file for literal text. It runs a fixed PowerShell script with -NoProfile and -NonInteractive. Callers cannot submit a command string. Every path must exist within one of the absolute, semicolon-separated directories in FOREMAN_READ_ROOTS. Unconfigured roots refuse file operations.

The runner limits file reads to 512 KB, directory listings to 200 entries, search matches to 100, and captured output to 1 MB. It refuses common credential files and the excluded LLM project. It has no write, network, provider dispatch, or shell execution tool. Point its roots only at reviewed Director-Orchestrator worktrees; do not include unrelated projects or an entire user profile.

Local validation: py -3.12 -m unittest tests.test_foreman_powershell_mcp -q. The test reads the repair procedure, lists its own module directory, searches a candidate source file, and refuses a path outside the configured worktree. This utility grants no repair, provider, review, or merge authority.

Local read access only.
