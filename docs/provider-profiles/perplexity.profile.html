Platform limitations

  • limitation
    Every Perplexity assignment requires an owner approval bound to the digest of the exact assignment; the Slack prompt shows the complete outbound query and a later mutation invalidates the approval.
    source
    docs/provider-setup.html, Perplexity research-only profile
  • limitation
    The raw Search API does not accept the search-context-size field; it is validated now for an optional future Agent API lane and not sent.
    source
    docs/provider-setup.html, Perplexity research-only profile
  • limitation
    Provider-reported cost may be incomplete; an API Platform budget control is the authoritative daily spend backstop.
    source
    docs/provider-setup.html, Perplexity research-only profile
  • limitation
    The adapter rejects draft-PR authority and any assignment whose estimated cost exceeds the daily budget; the lane also rejects every external effect.
    source
    docs/provider-setup.html; src/director_orchestrator/primary_default.py:_PRIMARY_PUBLIC_RESEARCH_LANES
  • limitation
    Browser provider-UI coordination is prohibited for this lane; Perplexity remains API-only.
    source
    docs/team-operating-charter.html, Browser communication transport
