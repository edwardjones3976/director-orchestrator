2. Memory rules for BlackBox (32 GB, bugchecks on record)

  1. Before every step and every model-related sub-step: Get-CimInstance Win32_OperatingSystem | Select-Object FreePhysicalMemory,TotalVisibleMemorySize. Record both. Proceed only with at least 8 GiB free; wait and re-measure once after 5 minutes if below; report and stop the step if still below.

  3. Docker Desktop stays off. The GPU stays idle. LM Studio: if any model is loaded (lms ps), unload it (lms unload --all) before H1 and keep it unloaded until H4 step 9.
  4. Hash files one at a time with a streaming hash (Get-FileHash -Algorithm SHA256), never in parallel jobs. No full-tree recursive hashing of C:\llm.
  5. After each step: Get-Process | Where-Object { $_.Name -match 'python|llama|lms|node|codex|ChatGPT' } | Select-Object Name,Id,WorkingSet64; end only processes this packet started; report any other that is above 2 GiB working set, do not end it.
